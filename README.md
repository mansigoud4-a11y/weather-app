# Weather App 🌤️

## Project Description
A responsive Weather App built using HTML, CSS, and JavaScript. It fetches real-time weather information using the free Open-Meteo public API.

## Features
- Search weather by city name.
- Display current temperature.
- Show humidity and wind speed.
- Loading state while fetching data.
- Error handling for invalid city names and API errors.
- Responsive design.

## Technologies Used
- HTML5
- CSS3
- JavaScript (ES6)
- Fetch API
- Async/Await
- Open-Meteo API

## Project Files
- index.html – App structure.
- style.css – App styling.
- script.js – API integration and functionality.

## How to Run
1. Download or clone this repository.
2. Open index.html in your browser.
3. Enter a city name.
4. Click Search Weather.

## API
https://open-meteo.com/

## Learning Outcomes
Learned asynchronous JavaScript, API integration, fetch(), async/await, and error handling.
